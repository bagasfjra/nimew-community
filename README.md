# nimew! - Komunitas & Hub Otaku Indonesia

> nimew! adalah platform berbasis web yang dirancang sebagai wadah berkumpul, berbagi informasi, dan berinteraksi bagi para penggemar budaya pop Jepang (anime, manga, game, dan pop culture) di Indonesia.

Latar Belakang & Tujuan
Komunitas penggemar budaya Jepang wibu di Indonesia tumbuh sangat pesat, namun informasinya sering kali tersebar di berbagai platform media sosial yang terpisah. 
nimew! hadir untuk:
* Menyediakan satu wadah terpusat yang ramah pengguna untuk berinteraksi dan berdiskusi.
* Memudahkan anggota komunitas menemukan informasi jadwal anime tayang, rekomendasi manga, dan event kebudayaan/pop culture Jepang terdekat.
* Membangun ruang diskusi interaktif yang inklusif bagi sesama penggemar.

Fitur & Section Utama
- Hero & Landing Section: Pengenalan singkat platform dengan tampilan visual bertema modern otaku.
- Anime & Manga Directory: Daftar rekomendasi, informasi tayang (seasonal anime), serta ringkasan cerita.
- Community Forum / Discussion: Space khusus pengguna untuk membuat postingan, berdiskusi, dan berbagi impresi episode terbaru.
- Event Calendar: Informasi jadwal acara cosplay, festival Jepang, dan pameran terkini.
- User Profile: Halaman profil anggota untuk mengelola daftar anime favorit dan aktivitas di platform.

Cara Menjalankan Secara Lokal
Menggunakan VS Code + Live Server
1. Install extension Live Server di Visual Studio Code.
2. Buka folder proyek ini di VS Code.
3. Klik kanan pada file `index.html`, lalu pilih "Open with Live Server".
4. Website akan otomatis terbuka di browser kamu.
